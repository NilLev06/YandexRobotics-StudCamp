# Yandex Robotics StudCamp 2026

Учебный репозиторий команды StudCamp: здесь собраны эксперименты, симуляторы и
программное обеспечение для реальных мобильных роботов и манипуляторов.

Наша цель — пройти полный путь робототехнического продукта: научить робота
видеть окружающий мир, строить карту, безопасно перемещаться, работать с
объектами и проверять поведение сначала в симуляции, а затем на физическом
оборудовании.

> **Важно:** часть кода управляет реальным оборудованием. Не запускайте команды
> движения или автономного поиска, пока робот не подготовлен и рядом нет
> ответственного оператора. Подробные ограничения находятся в ветке
> [`rover`](../../tree/rover/AGENTS.md).

## Карта репозитория

Разработка идёт в независимых ветках — так эксперименты с разными роботами не
мешают друг другу.

| Направление | Ветка | Что находится внутри |
| --- | --- | --- |
| Реальный мобильный робот | [`rover`](../../tree/rover) | ROS 2 Jazzy, YOLO, Nav2, SLAM, телеметрия и Docker-окружение для поиска объектов. |
| Обучение манипулятора | [`rl`](../../tree/rl) | Unity/ML-Agents: сцены, конфигурации и модели для обучения захвату и ловле объектов. |
| Реальный манипулятор в Unity | [`unity-real-manipulator`](../../tree/unity-real-manipulator) | Модель GFS-X, управление приводами, сенсоры, интеграция и защитные проверки для физического робота. |
| Базовые ассеты | [`main`](.) | Исходная Unity-сцена, модель и материалы; служит нейтральной точкой входа. |

Схема работы:

```text
Курс и гипотеза
       |
       +--> rl: обучаем поведение в Unity/ML-Agents
       |          |
       |          +--> Unity-манипулятор: проверяем интеграцию с оборудованием
       |
       +--> rover: зрение + SLAM + Nav2 на мобильном роботе
                  |
                  +--> безопасный поиск и телеметрия на реальном оборудовании
```

## С чего начать

1. Выберите направление в таблице выше и переключитесь на его ветку.
2. Прочитайте README выбранной ветки — в нём находятся требования и команды запуска.
3. Для `rover` сначала изучите `AGENTS.md` и `OBJECT_SEARCH.md`; проверки и запуск с движением — разные операции.
4. Для `rl` используйте Unity версии, зафиксированной в `ProjectSettings`, и зависимости из `Packages/`.

## Статус

Это учебно-исследовательский проект. Не все эксперименты завершены, а работа с
физическими роботами требует калибровки, проверки окружения и наблюдения
оператора. Документация намеренно фиксирует известные ограничения, а не скрывает
их за «готовым» интерфейсом.
