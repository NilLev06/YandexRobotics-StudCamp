# Rover: мобильный робот для поиска объектов

Эта ветка — рабочий контур реального мобильного робота RoboMarvel. Она
объединяет ROS 2, лидар, камеру, YOLO, SLAM, Nav2 и телеметрию, чтобы робот мог
безопасно искать заданный объект в известном или исследуемом пространстве.

> **Безопасность прежде запуска:** не выполняйте команду с движением только на
> основании README. Перед работой прочитайте [AGENTS.md](AGENTS.md) и
> [OBJECT_SEARCH.md](OBJECT_SEARCH.md), подтвердите свободное пространство и
> присутствие оператора. Для первого запуска используйте `--dry-run`.

## Назначение

Ровер на ROS 2 (Jazzy), который ищет заданный объект (пока — по фиксированному
слову, позже — по голосу) с помощью YOLO и безопасного поведения
поиска/подъезда с лидаром.

## Структура

```
.
├── config/          # что искать (target.txt) и калибровка камера-лидар
├── packages/        # ROS 2 пакеты: навигация, моторы/сенсоры, детекция, голос
├── scripts/         # запуск поиска и стрима камеры
├── mapping/         # отдельный модуль: живая карта (см. mapping/README.md)
├── docker/          # патчи для сборки образа
├── Dockerfile, docker-compose*.yaml, entrypoint.sh   # сборка и запуск контейнеров
├── OBJECT_SEARCH.md # как запускать поиск, заметки по безопасности
├── TELEMETRY.md     # чёрный ящик: постоянная запись всех данных ровера
├── VIO.md           # статус визуально-инерциальной одометрии, блокеры, план
└── YOLO_LIVE.md      # как запускать стрим камеры
```

Коротко: `config/` — за что отвечает "мозг" (что искать), `packages/` — глаза
(детекция), уши/рот (голос) и моторика (навигация + железо), `scripts/` —
кнопки запуска, остальное — Docker-обвязка.

## Как это работает вместе

```
config/target.txt  ──►  run_object_search.sh  ──►  object_search.py
                                                          │
                                    читает /health из     │  Nav2 Spin / NavigateToPose
                                    yolo_live_mjpeg.py ◄──┘         │
                                    (любой класс COCO)              ▼
                                                                 hwnode.py
                                                            (serial → моторы)
```

- **`yolo_live_mjpeg.py`** работает постоянно в своём контейнере
  (`docker-compose.yolo-live.yaml`) и отдаёт все детекции, которые видит — не
  только текущую цель — через `/health` (JSON) и как MJPEG-стрим по адресу
  `http://<ip-ровера>:8091/`.
- **`config/target.txt`** содержит одно слово — что ровер сейчас ищет.
  Пока редактируется руками; в будущем сюда будет писать голосовая нода.
- **`object_search.py`** — короткоживущий изолированный контейнер
  (`run_object_search.sh`), который проходит preflight-проверки безопасности
  (батарея, клиренс лидара, свежесть данных сенсоров), крутит ровер малыми
  шагами в поиске целевого класса и — только если калибровка подтверждена —
  подъезжает к нему через Nav2. Полную модель безопасности и инструкции по
  запуску см. в [OBJECT_SEARCH.md](OBJECT_SEARCH.md).
- **`explore_search.py`** — надстройка над `object_search.py` для комнат
  больше одного круга обзора: если полный оборот ничего не находит, едет к
  ближайшей неисследованной границе карты (`scripts/frontier.py`) и ищет
  снова. Тот же safety-контур и те же топики `/search/*`, `mapping/`
  ничего не меняет. См. [OBJECT_SEARCH.md](OBJECT_SEARCH.md#exploring-when-a-single-360-circle-isnt-enough).
- **`hwnode.py`** — единственное, что говорит с контроллером моторов по
  serial; всё остальное командует движением через ROS-топики/actions.
- **Телеметрия** ([TELEMETRY.md](TELEMETRY.md)) — "чёрный ящик": с загрузки
  ровера непрерывно пишет все топики (лидар, одометрия, батарея, команды,
  детекции), видео с камеры и системные метрики Pi; сессии по часу
  выгружаются на сервер и удаляются с ровера. Плюс живая веб-панель с
  графиками (`docker-compose.dashboard.yaml`, порт 8092) — без Prometheus/Grafana.
- **Карта** ([mapping/README.md](mapping/README.md)) — отдельный модуль,
  четыре независимых слоя (occupancy, след, найденные и замеченные объекты),
  комбинируются чекбоксами в браузере.

## Быстрый старт

```sh
# на ровере, внутри этой директории
docker start ros
docker compose -f docker-compose.yolo-live.yaml up -d   # оверлей камеры
echo "bottle" > config/target.txt
./scripts/run_object_search.sh --dry-run --search-only  # только preflight
./scripts/run_object_search.sh --search-only            # реальный поиск
```

Подробности, safety-гейты и коды завершения — в [OBJECT_SEARCH.md](OBJECT_SEARCH.md)
и [YOLO_LIVE.md](YOLO_LIVE.md).
