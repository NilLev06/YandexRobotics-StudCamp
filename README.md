# Unity: реальный манипулятор GFS-X

Эта ветка связывает Unity-модель гусеничного манипулятора GFS-X с контуром
реального робота. Она нужна для проверки наблюдений, действий, зрения и
телеметрии до работы с физическим оборудованием.

## Содержимое

| Каталог | Назначение |
| --- | --- |
| `amir-proj/` | Полный Unity-проект с моделью, сценами и интеграционным кодом. |
| `amir-proj/Assets/GFSXRealRobot/` | Адаптеры наблюдений и действий, preflight-проверки, приём данных зрения и телеметрия. |
| `amir-claw/` | Переносимый Unity-пакет робота, который можно добавить в другой проект. |

## Быстрый старт

1. Откройте `amir-proj/` через Unity Hub.
2. Используйте Unity `6000.0.79f1` и версии пакетов, зафиксированные в
   `amir-proj/Packages/manifest.json`.
3. Дождитесь полного импорта зависимостей и откройте нужную сцену из `Assets/`.
4. Для автономного поведения сначала проверяйте действия в симуляции.

Подробная инструкция по переносимому пакету робота находится в
[`amir-claw/README.md`](amir-claw/README.md).

## Безопасность

Компоненты в `GFSXRealRobot` предназначены для интеграции с физическим
манипулятором. Preflight-проверки и smoke-тесты не являются разрешением
двигать робота: перед подключением оборудования проверьте пространство,
ограничения приводов и назначьте оператора. Не переносите обученную политику
на реальный робот без отдельной контролируемой проверки.
