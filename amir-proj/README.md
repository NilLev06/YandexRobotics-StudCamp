# Amir GFS-X Unity project

Open this directory in Unity Hub with Unity `6000.0.79f1`.

For the physical robot and the latest Fixed ML-Agents model, follow
[`RealRobot/README.md`](RealRobot/README.md). That guide covers Pi deployment,
camera/YOLO startup, Unity validation, the two-step safety gates, and emergency
stop.

Generated Unity directories such as `Library`, `Temp`, `Logs`, and
`UserSettings` are intentionally not versioned.
